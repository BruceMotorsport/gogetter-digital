# Updated Scout Configuration

## Objective
Search freelance platforms for AI integration and web development jobs using browser automation. Focus on projects in the $500-$5000 range. Save details to lead files.

## Strategy
1. Use browser automation to navigate to job boards
2. Search for jobs with AI, web development, and mobile app development keywords
3. Extract job details including title, description, skills, and budget
4. Save qualified leads to appropriate files

## Target Platforms
- Freelancer.com
- Upwork.com
- Fiverr.com

## Keywords to Search For
- AI Development
- AI Integration
- Full Stack Development
- Mobile App Development
- Web Development
- Chatbot Development
- Machine Learning
- Automation

## Skills to Prioritize
- AI Development
- Full Stack Development
- Mobile App Development
- Web Development
- Node.js
- React
- Python
- JavaScript
- API Development
- Database Development

## Budget Range
Focus on jobs in the $500-$5000 range

## Output Format
Save leads in markdown format with:
- Job title
- URL
- Description
- Skills required
- Estimated budget
- GoGetter fit assessment
- Recommended action
