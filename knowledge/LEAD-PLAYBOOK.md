# GoGetter Digital - Lead Generation Playbook

## 🎯 How to Find Clients (Manual Process)

### Step 1: Check These Platforms Daily

**Fiverr Buyer Requests:**
1. Go to fiverr.com → Dashboard → Buyer Requests
2. Filter: "Website Design", "Mobile App", "AI Integration"
3. Look for: Budget $200+, 4+ star clients
4. Copy project details to leads folder

**Upwork Job Posts:**
1. Go to upwork.com/nx/search/jobs/
2. Search: "website design", "mobile app development", "AI chatbot"
3. Filter: Last 24 hours, Budget $200+
4. Copy job details to leads folder

**Freelancer Contests:**
1. Go to freelancer.com/contests
2. Search: "website", "app", "AI"
3. Copy contest details to leads folder

### Step 2: Score Each Lead

| Criteria | Points |
|----------|--------|
| Budget > $500 | +3 |
| Budget $200-500 | +2 |
| Clear requirements | +2 |
| Reasonable deadline | +1 |
| Client has history | +1 |
| Matches our skills | +1 |

**Score 7+ = Worth pursuing**

### Step 3: Create Proposal

Use this template:

```
Hi [Client Name],

I saw your project for [describe project]. I'd love to help!

I'm Corey from GoGetter Digital. We specialize in:
- [Relevant skill 1]
- [Relevant skill 2]
- [Relevant skill 3]

For your project, I'd:
1. [Step 1]
2. [Step 2]
3. [Step 3]

Timeline: [X] days
Budget: $[X]

I can start immediately. Want to hop on a quick call?

Best,
Bruce
GoGetter Digital
```

### Step 4: Save to Leads Folder

Create a file in `Desktop/gogetter-digital/leads/` with:
- Client name
- Platform
- Project description
- Budget
- Deadline
- Your score
- Proposal sent (yes/no)
